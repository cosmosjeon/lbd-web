### LBD Admin CMS 사양 (v0.2)

- 대상: 비개발자 운영진이 브라우저에서 모든 운영 기능을 쉽고 안전하게 수행
- 목표: 3클릭 이내 핵심 작업 완료, 오류 예방·복구 용이, 일괄 처리/승인 워크플로 제공

---

### 1) 정보 구조(좌측 내비게이션)

1. 대시보드
   - 오늘 일정, 미승인 항목, 출석 이상 감지, 구독/리크루팅 현황
2. 공지(멤버 전용)
   - 작성/수정/고정/예약, 미리보기, 버전 이력
3. 정보 페이지(기사/공고/공모전/행사)
   - 큐레이션/제보 승인, 태그/마감일, 외부 링크 검증
4. 출석
   - 세션 생성(반복), QR/코드 발급, 보정/사유 기록, 통계/CSV
5. 세션 자료
   - 주차/기수 관리, 파일 업로드(드래그&드롭), 권한(부원 전용)
6. 프로젝트 아카이브
   - 카드/상세 편집, 멤버/마일스톤/아티팩트 관리, Featured 토글, CSV 임포트
7. 아카이브(카페→웹)
   - `category_map.csv`/`naver_cafe_posts.csv` 업로드, 시뮬레이션, 매핑/삽입, 로그
8. 캘린더
   - 이벤트 CRUD, ICS 내보내기, 색상 규칙
9. 운영진 소개
   - 카드 편집(사진/직책/담당/링크), 정렬
10. 멤버 & 화이트리스트
   - `phone_e164` 업로드/편집, Admin 권한 토글, 승인/회수
11. 구독 리드
   - 이메일/전화, 동의 상태, CSV 내보내기
12. 설정
   - 브랜드 색/로고, 링크, 개인정보/약관 버전, 스토리지 버킷, 관리자 초대
13. 감사 로그
    - 작업 이력 검색/필터/CSV, 엔티티별 diff 확인

---

### 2) 공통 UX 원칙

- 데이터 테이블: 열 선택/정렬/필터/검색, 다중 선택 후 일괄 작업, CSV 내보내기
- 에디터: Tiptap 기반 리치텍스트(링크/리스트/이미지), 자동 저장, 스토리지 업로드
- 승인 흐름: 초안→검토→게시, 되돌리기(버전 저장)
- 안전장치: 파괴적 작업은 이중 확인, 소프트 삭제+복구, 감사 로그 남김
- 온보딩: 섹션별 가이드/툴팁, 실패 시 해결 도움말
 - 접근성: 데이터 테이블 키보드 조작, 라벨/설명/에러 연결(ARIA)

---

### 3) 접근 제어

- Admin만 쓰기 가능. Member는 CMS 접근 불가(프런트 공개 페이지만)
- 서버에서 RLS+서버 액션으로 2중 보호
 - 세션 타임아웃 및 자동 로그아웃(비활성 30분)

---

### 4) 일괄 처리/임포트

- CSV 템플릿 제공: 프로젝트/멤버/아티팩트, 카페 아카이브, 화이트리스트
- 업로드 흐름: 파일 업로드→전처리/검증 결과 프리뷰→확정 삽입→결과 로그 다운로드
 - 검증: 필수 컬럼/데이터 타입/중복 키 체크, 시뮬레이션 단계에서 오류 행만 다운로드 제공

---

### 5) 감사 로그(Audit)

- 기록: actor_user_id, action(create/update/delete/import), entity_type/id, diff, ip, user_agent, ts
- 뷰: 기간/사용자/엔티티 필터, CSV 내보내기
 - 보존 기간: 최소 180일

---

### 6) 품질/접근성

- 키보드 내비게이션, 포커스 스타일, ARIA 라벨, 에러 설명
- 실패 복구 메시지와 링크(문의/가이드)

---

### 7) 기술 스택(프런트)

- UI: shadcn/ui + Tailwind, DataTable: TanStack Table v8
- 폼: react-hook-form + zod, 업로드: Supabase Storage pre-signed
- 상태: React Server Components + 서버 액션, 캐시 무효화 패턴 적용
 - 보안: reCAPTCHA/Turnstile(공개 폼), 레이트 리밋 미들웨어

---

### 8) 수용 기준(샘플)

- 운영진은 `member_whitelist.csv` 업로드 후 1분 내 승인 반영을 확인할 수 있다
- 출석 세션 QR 생성/보정/CSV 추출을 페이지 이동 2회 이하로 완료할 수 있다
- 공지 작성은 미리보기/예약 게시/고정 기능을 포함한다
- 카페 임포트는 시뮬레이션에서 행별 성공/오류를 표시한다
 - 프로젝트 CSV 임포트는 중복 검출/롤백이 가능하며 결과 리포트를 다운로드할 수 있다
